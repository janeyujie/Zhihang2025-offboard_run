\section{项目简介}
本项目聚焦于“无人机双机协同自主搜救”这一前沿挑战，设计并实现了一套面向复杂动态环境的异构无人机协同智能决策系统。系统由一架垂起固定翼无人机（VTOL）作为广域侦察单元和一架四旋翼无人机作为精准响应单元构成。

任务流程分为两个核心阶段：
\begin{itemize}
    \item \textbf{阶段一：} VTOL无人机利用其航程远、效率高的优势，在大范围内执行自主航路规划、动态模式切换、躲避禁飞区及多目标实时感知任务，通过搭载的YOLOv8视觉感知模块，实现对三类模拟人员的精确识别与世界坐标解算。
    \item \textbf{阶段二：} 在完成侦察并回传目标数据后，四旋翼无人机接替任务，基于接收到的目标信息执行高精度路径规划与末端视觉伺服控制，分别对静态及动态目标进行稳定追踪与抵近，最终在要求的高度上，完成关键信息的精确发布，全过程无需人工干预。
\end{itemize}

% 2. 项目背景
\section{项目背景}
无人机技术在环境监测、应急通信和抢险救灾等领域的应用正迅速深化。尤其在灾后搜救等复杂场景中，地面人员往往面临视野受限、地形阻碍及二次坍塌等重大安全风险。无人机凭借其空中优势，能够快速获取全局态势，显著提升搜救效率并降低人员风险。

然而，单一无人机平台难以兼顾大范围搜索效率与近距离精准操作的需求。为此，\textbf{异构双机协同}已成为解决此类复杂任务的前沿范式。该模式利用：
\begin{itemize}
    \item VTOL无人机兼具多旋翼垂直起降灵活性与固定翼长航时巡航能力的特点，执行广域快速扫描
    \item 四旋翼无人机优越的悬停与机动性能，执行抵近侦察与精准任务操作
\end{itemize}

本项目正是在此背景下，针对包含禁飞区、多类别动态/静态目标识别以及双机任务交接的复杂协同搜救场景，研发一套高效、鲁棒的智能决策与控制算法，旨在验证并提升异构无人机集群在该类任务中的自主协同作业能力。

% 3. 项目目标
\section{项目目标}
本项目的核心目标是设计、实现并验证一套应用于异构双机协同搜救任务的\textbf{智能决策与控制算法}。该系统旨在模拟真实搜救场景，验证无人机在GPS信号存在噪声、目标部分动态的挑战下，从起飞到任务完成的全流程自主作业能力。

具体子目标分解如下：
\begin{enumerate}
    \item \textbf{高层任务规划与导航：} 实现 VTOL 无人机的全自主起降、飞行模式无缝切换，以及融合了禁飞区的全局路径规划与航点跟踪能力。
    \item \textbf{实时环境感知与目标定位：} 开发基于 YOLOv8 的机载视觉感知模块，实现对多类别目标的实时检测、分类，并构建从像素坐标到全局地理坐标的精确解算模型。
    \item \textbf{动态目标追踪与运动预测：} 针对动态目标，设计一套轨迹数据采样与运动模型拟合算法，实现对目标未来位置的有效预测，为精准拦截提供决策依据。
    \item \textbf{末端精准伺服与信息发布：} 为四旋翼无人机开发基于视觉反馈的闭环伺服控制算法，实现对目标的稳定抵近、对心悬停，并在满足竞赛规则的高度与精度要求下，完成关键信息的发布。
\end{enumerate}

\section{项目实施}
\subsection{阶段一：任务启动与广域巡航}
无人机A (\texttt{standard\_vtol\_0}) 执行任务初始化序列：
\begin{enumerate}
    \item 以多旋翼模式垂直起飞至预定安全高度
    \item 执行\textbf{多旋翼至固定翼的飞行模式转换}
    \item 激活全局路径规划模块，结合禁飞区约束，生成绕开禁飞区的无碰撞航路
    \item 飞抵指定的GPS引导点
\end{enumerate}

\subsection{阶段二：目标搜索、识别与信息共享}
抵达GPS引导点后：
\begin{itemize}
    \item 无人机A进入搜索模式，执行预设的覆盖式路径规划航线确保对指定搜索区域的完全覆盖
    \item 激活\textbf{机载视觉感知模块}（基于YOLOv8），对视频流实时处理，检测分类三类目标（危重、轻伤、健康）
    \item 通过坐标解算算法获取目标全局Pose，并通过ROS话题发布（实现与无人机B的机间数据链模拟）
    \item 完成目标搜索与信息发布后，自主返航至旋翼模式区
    \item 执行固定翼至多旋翼模式转换，垂直降落并自动锁桨
\end{itemize}

\subsection{阶段三：精准抵近与末端作业}
无人机A安全着陆后，无人机B (\texttt{iris\_0}) 自动解锁起飞：
\begin{itemize}
    \item 任务规划模块根据接收目标信息决策，规划前往健康人员（动态目标）的航路
    \item 抵达目标区域后，激活\textbf{末端视觉引导系统}：
    \begin{itemize}
        \item \textbf{健康人员：} 进入目标状态估计阶段，通过连续视觉检测采样拟合运动轨迹，建立运动模型，计算最优拦截点并前出至该点上空，下降至0.7米高度等待目标进入指定区域后发布平台坐标
        \item \textbf{重伤人员：} 激活视觉伺服控制逻辑，采用"对准-下降"递进策略，通过闭环控制修正水平位置，确保精确位于目标正上方，逐步下降至0.5米高度发布坐标
    \end{itemize}
\end{itemize}

\subsection{阶段四：任务完成与返航}
无人机B完成对两个指定目标的任务后：
\begin{enumerate}
    \item 执行返航程序，自主飞行返回旋翼模式区
    \item 执行自动降落、锁桨
    \item 标志着整个协同搜救任务的圆满完成
\end{enumerate}

\subsubsection{人工势场法原理与实现步骤}
人工势场法（APF）是一种受物理场启发的局部路径规划方法，由Khatib于1986年提出。其核心思想是将任务环境建模为一个虚拟势场：
\begin{itemize}
    \item \textbf{目标点}产生\textbf{引力场}，引导无人机向目标移动；
    \item \textbf{禁飞区}（视为障碍物）产生\textbf{斥力场}，迫使无人机远离危险区域；
    \item 无人机在\textbf{引力与斥力的合力方向}上运动，实现避障与趋近目标的统一。
\end{itemize}

设无人机当前位置为 $\mathbf{p} = (x, y)$，目标点为 $\mathbf{p}_g$，第 $i$ 个禁飞区中心为 $\mathbf{p}_{o_i}$，则：

\begin{enumerate}
    \item \textbf{引力计算}（通常采用线性模型）：
    \[
    \mathbf{F}_{\text{att}} = k_{\text{att}} (\mathbf{p}_g - \mathbf{p})
    \]
    其中 $k_{\text{att}} > 0$ 为引力增益系数，控制趋向目标的强度。

    \item \textbf{斥力计算}（仅在障碍物影响半径 $d_0$ 内生效）：
    \[
    \mathbf{F}_{\text{rep},i} =
    \begin{cases}
        k_{\text{rep}} \left( \frac{1}{\|\mathbf{p} - \mathbf{p}_{o_i}\|} - \frac{1}{d_0} \right) \frac{1}{\|\mathbf{p} - \mathbf{p}_{o_i}\|^2} \cdot \frac{\mathbf{p} - \mathbf{p}_{o_i}}{\|\mathbf{p} - \mathbf{p}_{o_i}\|}, & \|\mathbf{p} - \mathbf{p}_{o_i}\| \leq d_0 \\
        \mathbf{0}, & \text{otherwise}
    \end{cases}
    \]
    其中 $k_{\text{rep}} > 0$ 为斥力增益，$d_0$ 为斥力作用半径（通常略大于禁飞区半径）。

    \item \textbf{合力合成}：
    \[
    \mathbf{F}_{\text{total}} = \mathbf{F}_{\text{att}} + \sum_{i=1}^{N} \mathbf{F}_{\text{rep},i}
    \]

    \item \textbf{航向生成}：将合力方向转换为期望航向角：
    \[
    \theta_{\text{des}} = \operatorname{atan2}(F_y, F_x)
    \]
    并通过飞控系统（如PX4）发送航向或速度指令，驱动无人机沿势场下降方向运动。

    \item \textbf{阶段切换判断}：当 $\|\mathbf{p} - \mathbf{p}_g\| < r_{\text{vision}}$ 且斥力总和接近零时，判定已进入目标区域，停止APF导航，启动视觉识别进程。
\end{enumerate}

该方法计算高效、响应迅速，适用于禁飞区分布稀疏的中程导航场景。尽管存在局部极小值等理论缺陷，在本系统中通过合理设置势场参数与任务边界条件，可有效规避此类问题。

\subsubsection{避障策略}
基于上述人工势场法，系统实施以下避障策略：
\begin{itemize}
    \item 将每个禁飞区建模为圆形斥力源，确保无人机在其影响半径外保持安全距离；
    \item 通过调节 $k_{\text{att}}$ 与 $k_{\text{rep}}$ 的比例，在保证避障安全的前提下维持较高的巡航速度；
    \item 实时更新势场并重规划航向，适应动态环境变化（如新增临时禁飞区）；
    \item 当合力方向与当前飞行方向夹角过大时，引入平滑滤波或最大转弯率约束，满足固定翼无人机的动力学限制。
\end{itemize}

\subsection{detect\_stage1.py（阶段二）：基于视觉的目标识别与地理定位}

本模块实现利用 VTOL 无人机搭载的遥感系统，对地面目标进行实时检测、分类与高精度地理坐标定位。系统通过融合机载视觉感知与高精度位姿信息，完成从像素到世界坐标的端到端映射，为后续任务提供可靠的目标位置输入。

\begin{itemize}
    \item \textbf{数据同步}：通过消息队列（如 ROS 或 ZeroMQ）严格对齐同一时刻的 RGB 图像与无人机位姿（GPS + IMU）；
    \item \textbf{目标识别}：采用轻量化 YOLOv8 模型实现实时目标检测与多类别分类；
    \item \textbf{坐标解算}：基于针孔相机模型与刚体变换，将检测框中心像素映射至地理坐标系；
    \item \textbf{数据滤波}：对静止目标采用滑动窗口均值滤波以抑制定位抖动；对运动目标优先选取靠近图像中心（畸变最小区域）的观测结果，提升精度。
\end{itemize}

\subsubsection{遥感坐标转换模型}

系统采用经典的针孔相机成像模型，结合无人机位姿信息，将像素坐标逐步转换为地理坐标（ENU 或 WGS-84）。转换流程如下：

\begin{enumerate}
    \item \textbf{像素坐标 $\rightarrow$ 相机归一化方向向量}：  
    利用相机内参矩阵 $K$ 的逆变换，将像素 $(u, v)$ 转换为相机坐标系下的单位射线方向：
    \[
    \mathbf{p}_{\rm cam} = K^{-1} \begin{bmatrix} u \\ v \\ 1 \end{bmatrix} 
    = \begin{bmatrix} (u - c_x) / f_x \\ (v - c_y) / f_y \\ 1 \end{bmatrix}
    \]
    其中 $f_x, f_y$ 为焦距（像素单位），$(c_x, c_y)$ 为主点坐标。

    \item \textbf{相机坐标系 $\rightarrow$ 机体坐标系}：  
    通过外参（旋转 $R_{\rm cam\to body}$ 与平移 $\mathbf{t}_{\rm cam\to body}$）完成坐标变换：
    \[
    \mathbf{p}_{\rm body} = R_{\rm cam\to body}\,\mathbf{p}_{\rm cam} + \mathbf{t}_{\rm cam\to body}
    \]

    \item \textbf{机体坐标系 $\rightarrow$ 世界坐标系}：  
    利用飞控提供的无人机位姿（位置 $\mathbf{p}_{\rm UAV}$ 与姿态 $R_{\rm body\to world}$），将射线方向映射至全局坐标系：
    \[
    \mathbf{ray}_{\rm world} = R_{\rm body\to world}\,\mathbf{p}_{\rm body}
    \]

    \item \textbf{射线-地面交点计算}：  
    假设地面高度为 $z = z_{\rm ground}$，无人机相机中心高度为 $z_{\rm cam}$，则交点参数为：
    \[
    t = \frac{z_{\rm ground} - z_{\rm cam}}{\mathbf{ray}_{\rm world}[2]}, \quad 
    \mathbf{P}_{\rm target} = \mathbf{p}_{\rm UAV} + t \cdot \mathbf{ray}_{\rm world}
    \]

    \item \textbf{系统误差修正}：  
    考虑镜头畸变、IMU/GPS 延迟、地面起伏等因素，引入经验补偿项 $\mathbf{v}_{\rm error}$（可通过标定场校准）：
    \[
    \mathbf{P}_{\rm corrected} = \mathbf{P}_{\rm target} + \mathbf{v}_{\rm error}
    \]
\end{enumerate}

\subsubsection{方法优势分析}

相较于传统目标定位方法（如纯 GPS 标记、人工判读或基于特征匹配的 SfM），本方案具有以下显著优势：

\begin{itemize}
    \item \textbf{高时效性}：YOLOv8 模型在边缘设备上实现实时推理，支持动态目标跟踪；
    \item \textbf{高精度定位}：融合高精度位姿与几何投影模型，定位误差可控制在 1–3 米内（取决于飞行高度与标定质量）；
    \item \textbf{强鲁棒性}：通过消息队列严格同步图像与位姿，避免因异步导致的坐标漂移；
    \item \textbf{可扩展性强}：模型支持增量训练，可快速适配新目标类别；坐标转换模块兼容多种相机与无人机平台；
    \item \textbf{自动化程度高}：从检测到定位全流程无需人工干预，适用于大规模巡检或应急响应场景。
\end{itemize}

            \item MODELING: 采样并拟合运动轨迹

        \end{itemize}
        \item \textbf{重伤人员（静态目标）:}
        \begin{itemize}
            \item SEARCHING: 微调至目标正上方
            \item ALIGNING: 下降一段距离
            \item 重复直到下降到0.5米高度发布坐标
        \end{itemize}
    \end{itemize}
\end{itemize}
